# AutoWrong — Keyboard Engine

This directory contains the keyboard engine powering **AutoWrong**, the world's first intentionally-broken autocorrect keyboard.  
It is based on [HeliBoard](https://github.com/HeliBorg/HeliBoard), an open-source Android keyboard, and is distributed under the same **GPL-3.0** license.
